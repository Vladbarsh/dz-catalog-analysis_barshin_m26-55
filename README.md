# Домашнее задание №1

Баршин Владислав, группа М26-55.

Аналитика каталога стримингового сервиса. В каталоге 10 фильмов из задания.
Программа считает средний рейтинг и возраст фильмов, выводит топ-3 и статистику
по жанрам. Все функции находятся в `catalog_analysis.py`.

## Запуск

Нужны Python 3.12 и uv. В папке проекта:

```console
uv sync
uv run catalog_analysis.py
```

Проверка кода:

```console
uv run ruff check .
```

## Примеры из задания

При обычном запуске выводится итоговый отчёт. Остальные примеры можно запустить
отдельно:

```console
uv run python -c "from catalog_analysis import demonstrate_examples, movies; demonstrate_examples(movies)"
```

Здесь показаны результаты промежуточных этапов: категории фильмов, циклы,
словари, множества и генератор. Поиск фильма с рейтингом выше 9 проверяется
также на каталоге без таких фильмов — тогда выводится «Шедевров не найдено».

Возраст фильмов считается относительно 2026 года. Исходный список фильмов
не меняется; названия приводятся к нужному регистру при выводе отчёта.
